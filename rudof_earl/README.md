# rudof EARL

[EARL 1.0](https://www.w3.org/TR/EARL10-Schema/) (Evaluation and Report Language) reports.

EARL is the vocabulary the W3C uses to collect implementation reports:
one `earl:Assertion` per test, naming what was tested, against which criterion,
and with what outcome
